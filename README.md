# QA Portafolio Funcional

Portafolio de estudio de QA funcional, alineado con ISTQB Foundation Level (CTFL v4.0). Reúne el vocabulario, los mapas y los ejercicios prácticos que voy construyendo módulo a módulo, con ejemplos sobre la tienda de demostración [SauceDemo](https://www.saucedemo.com).

Credenciales usadas en las prácticas: usuario `standard_user` y contraseña `secret_sauce` (son las de la demo pública, no un secreto real).
